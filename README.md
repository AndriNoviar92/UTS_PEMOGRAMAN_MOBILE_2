# Aplikasi Qibla & Informasi Islami (Flutter)

Ini adalah skeleton project Flutter sesuai permintaan:
- SplashScreen
- Login
- Register
- Qibla Direction (menggunakan package `flutter_qiblah`)
- Informasi (GridView)
- Sidebar Navigation (Drawer)
- About (dengan Copyright by Andri Noviar_24552012009)

Cara menjalankan:
1. Pastikan Flutter sudah terinstall: https://flutter.dev
2. Buka terminal di folder project ini.
3. Jalankan `flutter pub get`
4. Jalankan `flutter run` (atau gunakan IDE seperti Android Studio / VS Code)

Catatan:
- Ini hanya skeleton (UI + navigasi). Anda mungkin ingin menambahkan autentikasi, penyimpanan data, atau pengaturan izin lokasi/sensor untuk qibla.
- Package penting sudah ditambahkan di pubspec.yaml: flutter_qiblah.
